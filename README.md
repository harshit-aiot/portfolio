## ⚡ Features

### 🌌 Interactive IoT Mesh Background
- A custom HTML5 Canvas particle network simulating sensor node nodes in an active telemetry grid.
- Responds to mouse movements with gentle attraction forces.
- Includes a floating **Telemetry Control** widget to adjust parameters dynamically in real time:
  - Node Density (20 to 180 particles)
  - Flow speed multiplier (0.2x to 3.0x)
  - Link Range connection limits (60px to 240px)
  - Color Theme selection (*Cyber Cyan*, *Matrix Code*, *Volcano Core*, and *Cosmic Neon*)
  - Interactive "Telemetry Burst" option to inject glowing scatter particles on command.

### 🎨 Premium Dark Aesthetics
- Handcrafted layout built using Vanilla CSS for lightweight, zero-dependency rendering.
- Glassmorphism UI elements featuring borders, glowing backdrops, and cybernetic ticker lines.
- Complete responsive design optimized for standard desktop screens down to mobile layouts.

### 📂 Dynamic Sections
- **Home:** Landing section showing key data processing statistics and rolling live telemetry raw mock logs.
- **Projects Showcase:** Interactive grid presenting real estate analysis dashboards, automated greenhouse systems, and signal processing robotics.
- **Biography:** Profile detailing skills (Python, SQL, Embedded C, ESP32, Power BI), experience, and Cisco-verified certifications.
- **Contact:** Terminal contact portal for active integrations.

## 🚀 Local Development

Follow these steps to run the portfolio locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/harshit-aiot/portfolio.git
cd "portfolio "
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open **[http://localhost:5173/](http://localhost:5173/)** in your browser to view the application.

### 4. Build for production
```bash
npm run build
```
The production-ready assets will be compiled into the `dist/` directory.

---

## 🌎 Deployment

The portfolio is deployed and hosted on **Vercel** with automatic production builds:
```bash
# Deploy preview
npx vercel

# Promote/Deploy to production
npx vercel --prod
```
